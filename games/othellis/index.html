ルール・操作

ルール

  • 白か黒のミノが落ちてくる
  • 置いた石で相手色を挟むと反転（8方向）
  • 1行が同じ色で埋まると消える
  • 赤線から下まで同じ色で積み上がった列も消える
  • 反転が起きた時だけ、反転した石を含む壁から壁までの同色の斜め線も消える（2マス以上）
  • 反転・消去の後、赤線より上に石が残っていたら終了

キー操作

  • ← → 移動（長押しで連続）
  • ↑ / X 右回転、Z 左回転
  • ↓ ソフトドロップ
  • Space ハードドロップ
  • Shift / C ホールド
  • Esc / P 一時停止

キーが効かないときは一度盤面をクリックしてください

遊び方

白か黒1色の、4個ひと組の石が落ちてくるパズルです。置いた石で相手の色を挟むと、8方向に裏返ります。同じ色で埋まった1行と、赤線から下まで同じ色の列は消えます。裏返しが起きた手では、裏返した石を含む壁から壁までの同色の斜め線も消えます。裏返しと消去のあとで赤線より上に石が残ると終わりです。

操作

スマホは画面下のボタンで操作します。↑は一気に落とすボタンで、ホールドは1個につき1回使えます。PC は←→で移動、↑か X と Z で回転、↓で少しずつ落とし、Space で一気に落とします。Shift か C がホールドで、Esc か P で一時停止します。

コツ

裏返しは1個10点ですが、1本500点の列や斜め、4行同時で800点の行消しのほうが大きく、こちらはレベルが倍率になります。レベルは10本消すごとに上がり、落下も速くなります。
