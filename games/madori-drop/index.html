玩法

落ちてくる部屋のブロックを横8マス、縦14マスに積み、一軒の間取りを作る落ちものゲームです。列を消す仕組みはなく、次のブロックが入らなくなると終わりです。家が3Dで建ち、家賃が結果になります。最高額はこのブラウザに保存されます。

操作

画面下のボタンで移動と回転をします。↓で早く、↑で一気に落とします。ホールドは1ブロックにつき1回です。PC は矢印キー、Z と X で回転、C でホールドです。完成後は「歩く」で家の中を見て回れます。

コツ

家賃は広さで上がり、浴室やトイレ、洗面所などで加算されます。トイレ、玄関、キッチンが無いと減額です。外に面していない居室も減額されます。同じ種類の部屋は隣り合うと1つにまとまります。
