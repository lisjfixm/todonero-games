C CPU対戦の切り替え

ルール

自分の色のブロックはすり抜ける。

相手の色のブロックは跳ね返り、自分の色に塗り替わる。

ボールは時間とともに速くなる。落とすと元の速さに返回。

相手のボールを打ち返すと自分の色になる。奪われて0個になった側は、すぐパドルから1個出る。

ボールを全部落とすと1秒間おあずけ。

制限時間（30秒）が切れた時点で、陣地の多いほうが勝ち。

背景画像

ブロックの部分を好きな画像2枚に置き換えられる。塗り替えるほど自分の画像が出てくる。

アイテム

塗り替えたマスから自陣に落ちてくる。パドルで受けると発動。

貫通：3秒間、跳ね返らず塗りながら進む
爆弾：次の1回、当たったマスの3×3を塗る
増殖：ボールが1個増える

玩法

手前の青と奥の赤に分かれ、ブロック崩しで陣地を塗り合う30秒の対戦です。ボールは自分の色のマスをすり抜け、相手の色のマスに当たると跳ね返り、そのマスを自分の色に変えます。時間切れの時点で、全120マスのうち多く塗ったほうが勝ちです。

操作

キーボード専用で、スマホの画面操作には対応していません。青は←→、赤は A と D でパドルを動かします。按空格開始と再戦を行い、C で赤を CPU に切り替えると1人でも遊べます。

コツ

相手のボールを打ち返すと自分のものになりますが、速さは基本に戻ります。自分のボールは時間とともに速くなり、全部落とすと1秒待って基本の速さから出直しです。塗り替えたマスからは3割の確率でアイテムが自陣へ落ちるので、パドルで受け取ってください。
